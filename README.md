# 3DVision2026

Interactive concept demos for the 3D Vision – NeRFs & INR course.

| Module | Page | Covers |
|---|---|---|
| 4 | [`module4/`](module4/) | 30 concepts from Lectures 4.1–4.3: reflectance models (Lambert, Phong, Cook-Torrance), albedo/normals/visibility, relighting and material editing, hash encodings, pruning, quantization and distillation, Gaussian splatting, MobileNeRF, quality metrics, AR occlusion, latency, LiDAR fusion, hyperspectral NDVI, dynamic and generalizable NeRFs |

Each page is a single self-contained HTML file. Open it in a browser, or enable GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root) to get a shareable link.

Keys: ← / → move between concepts. "Projector size" enlarges everything for class.
